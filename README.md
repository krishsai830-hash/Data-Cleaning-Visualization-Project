# 📊 Data Cleaning & Visualization Project

## 📌 Project Overview

The Data Cleaning & Visualization Project focuses on cleaning, preprocessing, analyzing, and visualizing retail sales data using Python.

The main goal is to transform raw and incomplete data into a structured and meaningful dataset and generate useful business insights through data visualization.

## 🎯 Project Objectives

- Identify and handle missing values.
- Detect and remove duplicate records.
- Identify and handle outliers.
- Perform data preprocessing and transformation.
- Conduct Exploratory Data Analysis (EDA).
- Create meaningful data visualizations.
- Generate insights from retail sales data.

## 📂 Dataset Information

The project uses a synthetic retail sales dataset containing 1,010 original records and 9 columns.

**Dataset Features:**
- Order ID
- Date
- Customer Age
- Gender
- Product Category
- Quantity
- Unit Price
- Payment Method
- City

The dataset includes missing values, duplicate records, and outliers for demonstrating data-cleaning techniques.

## ⚙️ Project Workflow

1. **Data Collection:** Load the raw retail sales dataset.
2. **Data Inspection:** Examine dataset structure, columns, and data types.
3. **Missing Value Handling:** Replace missing numerical values using median and categorical values using mode.
4. **Duplicate Removal:** Identify and remove duplicate records.
5. **Outlier Treatment:** Detect outliers using the IQR method and apply capping.
6. **Data Preprocessing:** Convert date formats and create additional features.
7. **Exploratory Data Analysis:** Analyze sales by category, city, payment method, and customer demographics.
8. **Data Visualization:** Generate charts to understand sales patterns.
9. **Business Insights:** Identify top-performing categories, cities, and payment methods.
10. **Data Export:** Save the cleaned dataset as a CSV file.
